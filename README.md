# Math Tasks: Programming & Visualization

This repository contains small programming tasks focused on mathematical and probabilistic problems, implemented as standalone CLI programs.

Each task lives in its own directory and includes a detailed description and usage instructions. To run Python simulations, it's possible to use folder name as 'script name' for Python because of `__main__.py` file inside.
